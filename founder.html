About the founder

Rutik Dandelu is the founder of Tolvix, an independent online tools platform created to make everyday digital tasks easier to complete. He began building Tolvix in 2026, at the age of 20.

Tolvix brings together browser-based utilities for tasks involving text, calculations, images, PDF documents, developer workflows and learning. The project focuses on making useful tools accessible online without requiring users to install a separate application for every task.

About Tolvix

Tolvix is an independent project. Its website provides a directory of free online tools and practical guides. Tool capabilities, browser compatibility and privacy practices can vary by feature, so users should read the instructions and privacy information on the relevant pages.
