Binary, Decimal and Hexadecimal Numbers Explained

The same integer can be represented in binary, decimal or hexadecimal; only the notation changes.

← Back to Tolvix tools

Reviewed 6 November 2026. This practical guide explains the decisions and checks that help you use the related tool correctly.

Understand the task

Decimal uses ten symbols, binary uses 0 and 1, and hexadecimal uses sixteen symbols: 0–9 and A–F. Each position represents a power of the base. Binary 1011 means 8 + 0 + 2 + 1, which equals decimal 11.

Important details to check

Hexadecimal is compact because one hex digit represents four binary bits. It is common in colour values, memory addresses and debugging. The digits 10 represent ten in decimal, two in binary and sixteen in hexadecimal, so always identify the base.

Recommended workflow

Enter a whole number, select its current base, choose a target base and compare the output with a small example you can calculate by hand.

Worked conversions

To convert binary 1101 to decimal, calculate 1×8 + 1×4 + 0×2 + 1×1 = 13. To convert decimal 26 to hexadecimal, divide by 16: the quotient is 1 and the remainder is 10, written as A, so the answer is 1A.

For a quick check, convert the result back to the starting base. If 1A in hexadecimal does not return 26 in decimal, review the input base or a digit.

Common mistakes

  • Reading digits in the wrong base: 10 means ten in decimal but two in binary.
  • Dropping leading zeroes: numeric value is unchanged, but fixed-width binary data may require them.
  • Mixing signed and unsigned values: a bit pattern can represent different values depending on the convention and bit width.

Step-by-step conversion checklist

  1. Write down the source base and target base.
  2. Check that every input digit is valid for the source base.
  3. Convert a small example by hand or use place values to verify the result.
  4. Preserve leading zeroes when a protocol or fixed-width field requires them.

Frequently asked questions

Is hexadecimal a different value from decimal? No, it is another notation. Why does binary use two symbols? Base 2 has two digit symbols.
