Binary, Decimal and Hexadecimal Numbers Explained

The same integer can be represented in binary, decimal or hexadecimal; only the notation changes.

← Back to Tolvix tools

Reviewed 6 November 2026. This practical guide explains the decisions and checks that help you use the related tool correctly.

Understand the task

Decimal uses ten symbols, binary uses 0 and 1, and hexadecimal uses sixteen symbols: 0–9 and A–F. Each position represents a power of the base. Binary 1011 means 8 + 0 + 2 + 1, which equals decimal 11.

Important details to check

Hexadecimal is compact because one hex digit represents four binary bits. It is common in colour values, memory addresses and debugging. The digits 10 represent ten in decimal, two in binary and sixteen in hexadecimal, so always identify the base.

Recommended workflow

Enter a whole number, select its current base, choose a target base and compare the output with a small example you can calculate by hand.
