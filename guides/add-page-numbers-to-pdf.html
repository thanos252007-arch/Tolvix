How to Add Page Numbers to a PDF

Choose a numbering position, check the sequence and prepare a PDF that is easier to navigate.

Page numbers help readers navigate long reports, study notes, manuals and scanned documents. Before adding numbers, check whether the document already has printed page labels and decide whether the cover page should be counted.

Plan the numbering

  • Choose a position such as top or bottom and left, centre or right.
  • Check whether the cover page should display a number.
  • Decide whether numbering should begin at 1 or continue an existing sequence.
  • Make sure the number will not cover text, footnotes or signatures.

Add numbers step by step

  1. Open the Tolvix PDF Page Number tool.
  2. Select the PDF document.
  3. Choose the available position and numbering options.
  4. Generate and download the updated PDF.
  5. Open the output and inspect the first, middle and final pages.

Common issues

If a number overlaps existing content, choose another position or use a margin where possible. If a document has pages rotated in different directions, inspect those pages individually. Keep an original copy so you can start again without losing the source.

Printed page labels versus PDF page positions

A PDF viewer counts pages by their position in the file, while a document may already show printed page labels such as i, ii, 1 or 2. If a cover page or contents page should not display a number, decide whether numbering should start later and whether the visible label should match the PDF viewer's page count. Preview the first few pages to make sure the placement does not overlap headings, footers or existing text.

Final checks before sharing

  • Check the first numbered page and the final page.
  • Confirm that the numbers follow the correct sequence.
  • Inspect pages with different orientations or unusual margins.
  • Keep an untouched copy in case the numbering needs to be changed.

Adding visible page numbers does not necessarily change the document's internal page labels or bookmarks. If a recipient requires a specific numbering convention, confirm the exported file against those instructions.

Frequently asked questions

Can I skip the cover page?

Use a start-page or offset option if the tool provides one. Check the output before sharing.

Do page numbers change the original?

The tool should create an updated output file; retain the original PDF as a backup.

Are added numbers searchable?

That depends on how the PDF editor writes the numbering layer. Test text selection or search in the output if this matters.
