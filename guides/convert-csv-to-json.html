How to Convert CSV Data to JSON Objects

Convert a comma-separated table into a JSON array of objects by using the first CSV row as field names and each following row as a record.

← Back to Tolvix tools

Reviewed 13 November 2026. CSV and JSON both store structured information, but they organise it differently. CSV uses rows and columns; JSON can represent each row as an object with named properties. This guide walks through a practical CSV-to-JSON conversion and the checks to make before using the result in an app, API or assignment.

How CSV headers become JSON keys

For a typical table, the first CSV row contains column headings. Those headings become the keys in each JSON object. The values in the next row become that object's values, and every later data row becomes another object in the array.

Example: convert CSV to JSON

Start with this small comma-separated file:

name,city,age
Asha,Pune,21
Ravi,Mumbai,23

The header row defines three keys: name, city and age. The two remaining rows become two objects in a JSON array:

[
  {
    "name": "Asha",
    "city": "Pune",
    "age": "21"
  },
  {
    "name": "Ravi",
    "city": "Mumbai",
    "age": "23"
  }
]

Notice that the values are shown as strings. CSV is plain text and does not reliably declare whether a value is a number, date, Boolean or identifier. Convert values to the types your application expects after checking the source data.

Check CSV formatting before conversion

  • Headers: use unique, non-empty column names. Duplicate headings can make the output ambiguous.
  • Commas inside values: a value such as a company name or address may itself contain a comma. CSV quoting rules are used to keep that comma inside one field.
  • Quotation marks: embedded quotation marks are represented using CSV escaping rules. Inspect the converted value if your source contains quotes.
  • Empty cells: decide whether a blank should remain an empty string, become null, or be handled another way in your application.
  • Different delimiters: some exports use semicolons or tabs instead of commas. Check the file's delimiter before pasting it into a comma-separated converter.
  • Uneven rows: make sure each record has the expected number of fields so values do not shift into the wrong keys.

What to verify in the JSON output

JSON syntax can be valid while the data is still wrong. Compare the number of input records with the number of output objects, confirm that each value appears under the intended key, and look for missing or shifted fields. If the data will be sent to an API, check its required property names and data types as well.

Frequently asked questions

How do I convert CSV to JSON online?

Use the first CSV row as headers, paste the comma-separated data into a converter, run the conversion and inspect the resulting array of objects. You can try the free Tolvix CSV to JSON tool in your browser.

Can I connect a CSV file directly to a JSON API?

Usually, the CSV must first be converted into the JSON structure expected by the API. Check the API's required keys, data types and validation rules; converting the format alone does not guarantee that the API will accept the data.

Does CSV preserve numbers and dates as JSON types?

No. CSV stores text fields and does not reliably preserve data types. Review values such as numbers, dates, postal codes and IDs, then convert them deliberately if your application requires another type.

What if my CSV uses semicolons instead of commas?

Check the delimiter used by the export. A semicolon-separated file is not the same as ordinary comma-separated input, so convert or normalise the delimiter before using a comma-separated converter.

Why should I validate the JSON after conversion?

Validation catches malformed syntax, but you should also check the meaning of the data: field names, row counts, missing values and types must match what the next application expects.
