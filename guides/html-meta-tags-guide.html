How to Write HTML Title and Meta Description Tags

Metadata lives in the head of an HTML document. It helps describe a page to browsers, search engines and social platforms. Good metadata is not a shortcut to rankings: it should accurately represent the visible page and make search snippets or shared links clearer.

Write a distinct page title

The HTML title is commonly shown in browser tabs and may be used as the clickable search-result title. Describe the page's actual subject early, add a brand name when useful, and avoid repeating keyword variations. Each important page should have a distinct title. A title that promises a calculator should lead to a page that actually provides that calculator.

Write a useful meta description

A meta description is a concise summary that may be used as the search snippet. State what the page helps someone do and include a meaningful differentiator only if it is true. Search engines can generate a different snippet from page content, so do not treat the description as guaranteed copy or a guaranteed ranking factor.

Use canonical URLs carefully

A canonical link identifies the preferred URL among duplicate or very similar versions. Use an absolute HTTPS URL on the correct hostname and point it to the preferred indexable page. Do not copy the homepage canonical onto every page. Canonicalization is a hint, not a command, and should agree with redirects, internal links and sitemap URLs.

Example: write metadata for one page

For a page about compressing photographs, a clear title might be Image Compressor – Reduce JPG, PNG and WebP Size | Brand. A useful description would explain the actual task and supported formats, rather than repeating a list of keywords. The canonical URL should be the preferred public URL for that specific page—not the homepage URL copied across the whole site.

After publishing, inspect the page source and confirm that the title, description and canonical are present once and match the page content. Social platforms may cache previews, and search engines can choose a different title or snippet, so metadata should be accurate and helpful even when it is not displayed exactly as written.

Add social preview metadata

Open Graph title, description and image help platforms create link previews. Use a representative image with a stable public URL and appropriate dimensions. Keep social descriptions accurate and check the preview after publishing; platforms may cache older metadata.
