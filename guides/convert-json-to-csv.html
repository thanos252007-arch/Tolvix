How to Convert JSON to CSV: Step-by-Step Example for Spreadsheets

Turn a JSON array of records into spreadsheet-friendly CSV, understand how keys become headers and avoid common data-conversion problems.

← Back to Tolvix tools

JSON and CSV store data differently. JSON can represent nested objects and arrays, while CSV is a flat table. The simplest conversion starts with an array of objects: each object becomes a row and its keys become column headers. Try the Tolvix JSON to CSV Converter.

What JSON structure converts cleanly to CSV?

An array of objects with similar fields is usually the easiest input:

[
  {"name":"Asha","city":"Pune","score":92},
  {"name":"Kabir","city":"Mumbai","score":85}
]

The corresponding CSV is:

name,city,score
Asha,Pune,92
Kabir,Mumbai,85

In this simple example, the keys become headers and each object's values fill one row.

How to convert JSON to CSV online

  1. Check that your JSON is valid and that the top-level value is a supported array of records.
  2. Open the JSON to CSV Converter.
  3. Paste or enter the JSON data as requested by the tool.
  4. Run the conversion and review headers and rows.
  5. Copy or download the CSV using the available controls.
  6. Open a test copy in your spreadsheet and check column alignment and data types.

What happens when JSON objects have missing keys?

If one object has a key that another lacks, the output needs consistent headers and a blank or placeholder in the missing cell. Check row alignment rather than assuming every object has identical properties.

How are nested objects and arrays converted?

CSV has no native nested-object structure. A nested value may be flattened into a column name, serialized as JSON text, or handled according to the converter's implementation. Inspect these cells. If your spreadsheet needs separate columns, decide how to flatten the nested data before conversion.

Why do commas, quotes and line breaks matter?

A CSV field containing a comma, quotation mark or line break must be escaped or quoted correctly. For example, a value like Patel, Riya must not accidentally shift the next value into a new column. A well-formed CSV writer quotes such fields and escapes embedded quotes.

Why did Excel or another spreadsheet change my data?

Spreadsheet applications may automatically interpret values as dates, numbers or scientific notation. Long identifiers, postal codes and values with leading zeroes can be reformatted. Import a copy and set identifier columns to text when exact characters matter. Keep the original JSON as your source of truth.

Common JSON-to-CSV errors

  • Malformed JSON with a missing comma, quote or bracket.
  • Providing a single object when an array of objects is expected.
  • Assuming nested data automatically becomes separate columns.
  • Not checking rows with missing keys or different field order.
  • Letting spreadsheet software reformat identifiers.

Frequently asked questions

Can I convert any JSON file to CSV?

Not every structure maps directly to a flat table. Arrays of objects are the most straightforward; nested data may need flattening.

Does CSV preserve JSON data types?

CSV is a flat text format and does not preserve the full JSON type system or nested structure. Check how the receiving application interprets columns.

Can CSV contain commas inside a value?

Yes. The field must be quoted and embedded quotes escaped according to CSV rules.

How do I convert CSV back to JSON?

Use the CSV to JSON Converter after checking the header row and data types.
