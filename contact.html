Contact Tolvix

We welcome bug reports, feedback and suggestions for new tools.

Report a problem

The best way to contact the Tolvix project is through the Tolvix GitHub Issues page. Issues are public by default, so do not include confidential information.

What to include in a useful bug report

  1. Share the exact Tolvix page URL where the problem occurred.
  2. Describe the steps that reproduce it, in the order you performed them.
  3. Tell us what you expected and what actually happened.
  4. If relevant, include your browser and device type, plus a non-sensitive error message.

A short example input can help explain a problem, but remove names, account details, private documents, access tokens and other confidential information before posting. Never upload passwords, payment details or private files to a public issue.

Suggest a tool or improvement

Tell us what task you want to complete, who the tool would help and what input or output you expect. Suggestions that describe a real use case are easier to evaluate than a tool name alone. You can also request clearer instructions, report an accessibility problem or point out an error in a guide.

Privacy questions

For questions about the information described in our Privacy Policy, you can open a general issue without including personal data. Tolvix does not currently provide a private customer-support portal or publish a support email address.

Response expectations

Tolvix is an independent project, not a staffed support desk. Reports are reviewed when possible, but we cannot promise a response time, a fix or that every feature request will be implemented. Thank you for helping us improve the site.
