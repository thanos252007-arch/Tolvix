Contact Tolvix

Need help or want to contact the Tolvix team? Email support@tolvix.in for support questions and private enquiries.

Email support and privacy enquiries

Our public support email address is support@tolvix.in. Select the address to open your email app. You can use it for product support, website feedback, accessibility concerns, privacy requests and other private enquiries.

Please describe your question clearly and include the relevant Tolvix page URL when helpful. Do not email passwords, payment card details, access tokens or other sensitive information. If you need to report a security issue, describe it without including information that could put an account or person at risk.

Report a problem

You can also report bugs or request improvements through the Tolvix GitHub Issues page. Issues are public by default, so do not include confidential information there.

What to include in a useful bug report

  1. Share the exact Tolvix page URL where the problem occurred.
  2. Describe the steps that reproduce it, in the order you performed them.
  3. Tell us what you expected and what actually happened.
  4. If relevant, include your browser and device type, plus a non-sensitive error message.

A short example input can help explain a problem, but remove names, account details, private documents, access tokens and other confidential information before posting. Never upload passwords, payment details or private files to a public issue.

Suggest a tool or improvement

Tell us what task you want to complete, who the tool would help and what input or output you expect. Suggestions that describe a real use case are easier to evaluate than a tool name alone. You can also request clearer instructions, report an accessibility problem or point out an error in a guide.

Response expectations

Tolvix is an independent project, not a staffed support desk. Messages and reports are reviewed when possible, but we cannot promise a response time, a fix or that every feature request will be implemented. Thank you for helping us improve the site.
