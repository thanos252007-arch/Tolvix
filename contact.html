Contact Tolvix

We welcome bug reports, feedback and suggestions for new tools.

Report a problem

The best way to report a problem is through the Tolvix GitHub Issues page. Please mention the page or tool, the steps that caused the issue, what you expected to happen and what happened instead.

Open Tolvix GitHub Issues →

Suggest an improvement

You can also use GitHub Issues to suggest a new tool or an improvement to an existing one. Please do not post passwords, private documents or other sensitive information in a public issue.

Response expectations

Tolvix is an independent project. We review messages when possible, but a response or resolution time is not guaranteed.

What to include in a useful bug report

  1. Share the exact Tolvix page URL where the problem occurred.
  2. Describe the steps that reproduce it, in the order you performed them.
  3. Tell us what you expected and what actually happened.
  4. If relevant, include your browser and device type, plus a non-sensitive error message.

A short example input can help explain a problem, but remove names, account details, private documents, access tokens and other confidential information before posting. GitHub Issues are public by default, so assume that anything submitted there can be seen by other people.

Privacy and sensitive requests

Please do not use a public issue to send private documents, passwords, payment information or sensitive personal data. Tolvix does not provide a private customer-support portal at this time. For questions about the information described in our Privacy Policy, use the public issue page only for a general question and do not include personal data.

Suggest a new tool

Tell us what task you want to complete, who the tool would help and what input or output you expect. Suggestions that describe a real use case are easier to evaluate than a tool name alone. You can also report confusing instructions or request an accessibility improvement.

Response expectations

Tolvix is an independent project, not a staffed support desk. Reports are reviewed when possible, but we cannot promise a response time, a fix or that every feature request will be implemented. Thank you for helping us improve the site.
