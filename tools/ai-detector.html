How to use this tool

  3. Read the explanations and check any edited wording yourself.

What the analysis checks

The review looks for sentence-length consistency, repeated sentence openings, repeated content words, selected formal transitions and common filler phrases. It reports the text features it can observe; it does not infer who wrote the text.

Important limitations

No simple browser-based checklist can reliably determine whether a passage was written by a human or generated by AI. This tool does not use a machine-learning model, does not calculate an AI probability and must not be used as proof of authorship or as the sole basis for academic, employment or disciplinary decisions.

The clarity editor uses a limited set of phrase substitutions and whitespace cleanup. It may make no changes when no matching phrases are present. It does not promise to bypass AI detectors or produce a “0% AI” result.
