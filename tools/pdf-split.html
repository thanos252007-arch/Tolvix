How to use

Extract selected pages or page ranges from a PDF. Choose your file or enter the requested content, select options, then run the tool and download the result.

Choose the correct page range

PDF viewers usually display pages by their position in the file. Printed page numbers may differ because a document can include a cover, contents pages, Roman-numeral front matter or sections that restart numbering. Use the viewer's page position when selecting a range, then open the extracted file to confirm it contains the pages you intended.

After extracting pages

  • Check the first and last page in every output file.
  • Confirm that no page was skipped or included twice.
  • Give each output a clear filename before sharing.
  • Keep the original document until the split files are checked.

Splitting a PDF does not redact information from a page. If a page contains sensitive content, use a proper redaction method rather than assuming that extracting only some pages makes the remaining content safe.

Privacy and limitations

Processing happens locally in your browser. The page loads standard analytics and, for PDF tools, a third-party PDF library. Some advanced document features may not survive conversion. Check outputs before relying on them.

Frequently asked questions

Are my files uploaded?

No. File processing runs in your browser; the selected file is not sent to a Tolvix processing server.

Will all features be preserved?

Not always. Browser-based conversion may not preserve every annotation, form, font or advanced document feature.
