How to use Markdown Table Generator

  1. Enter column headings separated by commas.
  2. Enter one data row per line, with values separated by commas.
  3. Choose left, center or right alignment.
  4. Generate the Markdown and inspect the preview text.
  5. Copy it into your Markdown editor and check the rendered table.

What to know

Markdown tables use pipe characters to separate cells and a divider row to separate headings from data. Different Markdown renderers support slightly different extensions, so preview the result in the platform where you plan to publish it.

Frequently asked questions

Can cells contain commas?

This simple generator treats commas as separators. If a cell itself contains a comma, use another delimiter or edit the generated Markdown manually.

How do I include a pipe inside a cell?

The generator escapes pipe characters as backslash-pipe so they are not mistaken for column separators.

Will every platform render tables?

Most popular Markdown platforms support pipe tables, but the original Markdown specification does not require every renderer to implement them.
