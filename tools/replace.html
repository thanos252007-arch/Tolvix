How to find and replace text

  1. Paste or type your original text in the Your text box.
  2. Enter the exact characters or phrase to search for in Find.
  3. Enter the replacement in Replace with. Leave this field empty if you want to remove the matching text.
  4. Select Run tool, review the result, then use Copy result if it is correct.

The tool replaces every exact, case-sensitive occurrence of the find text. It does not offer whole-word matching, regular expressions or case-insensitive search. It is free to use without registration. See our Privacy Policy and Terms.

Update a repeated name

Original: “The Acme report is ready. Send the Acme report to the Acme team.”

Find: Acme · Replace with: Northstar

Result: “The Northstar report is ready. Send the Northstar report to the Northstar team.”

Remove a phrase

Original: “Draft — Meeting notes — Draft”

Find: Draft — · Replace with: leave blank

Result: “Meeting notes — ”

Matching behaviour and common mistakes

  • Case matters: searching for apple does not replace Apple or APPLE.
  • Partial matches are replaced: searching for cat also matches those letters inside catalogue. Check the result if you only intended a complete word.
  • Every match is replaced: the tool changes all exact occurrences, not just the first one.
  • Replacement text is literal: punctuation, spaces and line breaks in the replacement are inserted as entered.
  • An empty search is not run: enter at least one character in the Find field.

Review before using the result

Keep a copy of the original before bulk edits. Check names, dates, URLs, email addresses, code identifiers and punctuation in context. A text replacement tool does not understand grammar or know whether a changed phrase is appropriate in every sentence.

Frequently asked questions

Does it replace every occurrence?

Yes. It replaces every exact occurrence of the search text in the supplied passage.

Is the search case-sensitive?

Yes. Uppercase and lowercase letters must match exactly. For example, Report and report are different searches.

Can I replace a complete word only?

This tool uses exact substring matching, not whole-word matching. A short search can match part of a longer word, so review the output before copying it.

Can I delete text instead of replacing it?

Yes. Enter the text to find and leave the Replace with field empty. All exact matches will be removed.
