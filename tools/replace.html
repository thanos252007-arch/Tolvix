Use find and replace carefully

Find-and-replace is useful for correcting a repeated typo, updating a product name, standardising labels or changing a phrase across a block of text. Before replacing, decide whether the search should match upper- and lowercase letters and whether the complete phrase or a shorter substring is intended. A short search term can also match parts of other words.

Review the result

  • Keep a copy of the original text before making bulk replacements.
  • Use a distinctive phrase rather than a very common letter sequence.
  • Check the first few and last few replacements in context.
  • Review URLs, email addresses, code and identifiers before using the changed text.

This tool performs text replacement; it does not understand grammar or decide whether a replacement is appropriate in every sentence.
