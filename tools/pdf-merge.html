How to use

Combine multiple PDF documents into one PDF. Select at least two PDF files, arrange them in the intended order, merge them, and download the combined document. Keep the originals until you have checked the result.

Prepare documents in the right order

Before merging, arrange the source PDFs in the sequence the final document should follow. If a source contains unwanted pages, split or edit it before combining the files. Check whether the source documents use different page sizes or orientations; the merged PDF may contain a mixture of page dimensions.

What to verify in the merged file

  • Check the total page count and the order of each source document.
  • Open pages from the beginning, middle and end of the output.
  • Inspect forms, bookmarks, annotations and digital signatures if they matter.
  • Keep the originals until the merged version is accepted.

Combining pages may change or discard some interactive PDF features. Editing a signed document can invalidate its digital signature; do not assume a merged file retains the original signature's validity.

Privacy and limitations

Processing happens locally in your browser. The page loads standard analytics and, for PDF tools, a third-party PDF library. Some advanced document features may not survive conversion. Check outputs before relying on them.

Frequently asked questions

Are my files uploaded?

No. File processing runs in your browser; the selected file is not sent to a Tolvix processing server.

Will all features be preserved?

Not always. Browser-based conversion may not preserve every annotation, form, font or advanced document feature.

When should you merge PDF files?

Merging is useful when combining application pages, scanned documents, reports or supporting material into one file. Put the cover page and main document first, then add appendices in the order requested by the recipient.

Before submitting the merged PDF

  • Check that every required source file was selected.
  • Confirm the page sequence and orientation.
  • Open the downloaded PDF in a separate viewer.
  • Check file-size limits and submission instructions.

Editing or combining signed documents can affect digital-signature validation.
