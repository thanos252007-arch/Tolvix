Three common percentage questions

What is X% of a number? Multiply the number by X and divide by 100. What percentage is one number of another? Divide the part by the whole and multiply by 100. What is the percentage change? Subtract the original value from the new value, divide by the original value and multiply by 100.

Choose the correct base value

Percentage results depend on the reference amount. A change from 80 to 100 is a 25% increase, because the difference of 20 is compared with the original 80. A change from 100 back to 80 is a 20% decrease, because the same difference is compared with 100.

When the original or base value is zero, percentage change is undefined. Check which number is the starting value before interpreting the result.

Worked percentage examples

  • 18% of ₹1,500: 1,500 × 18 ÷ 100 = ₹270.
  • What percent is 45 of 180? 45 ÷ 180 × 100 = 25%.
  • Increase from 80 to 100: the increase is 20; 20 ÷ 80 × 100 = 25%.

For percentage change, compare the difference with the original value—not the new value. If the original value is zero, percentage change is undefined.

Frequently asked questions

How do I calculate a percentage of a number?

Multiply the number by the percentage and divide by 100. For example, 15% of 200 is 30.

How do I calculate percentage increase?

Subtract the original value from the new value, divide the difference by the original value, then multiply by 100.

Can percentage change be calculated from zero?

The usual percentage-change formula is undefined when the original value is zero. Use the actual difference or another suitable measure instead.
