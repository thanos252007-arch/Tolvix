How to use Meta Tag Generator

  1. Enter a concise page title and a useful description that accurately summarize the page.
  2. Add the canonical URL of the preferred, indexable version of the page.
  3. Optionally add an Open Graph image URL that is publicly accessible.
  4. Generate and copy the snippet into the document head.
  5. Publish, view-source the page and verify that canonical and social URLs are correct.

What to know

Metadata helps browsers, search engines and social platforms understand and preview a page. A generated snippet is only a starting point: each page should have an accurate, distinct title and description, and its canonical URL must point to the preferred live page.

Frequently asked questions

Does a meta description guarantee a ranking boost?

No. Search engines may use the description as a snippet, rewrite it, or choose page text. It is not a guaranteed ranking factor.

What should a canonical URL contain?

Use the full preferred absolute URL, normally HTTPS, with the correct hostname and path. Do not canonicalize unrelated pages to one URL.

Can every page use the same title?

No. Give each indexable page a distinct title that describes its actual purpose.
