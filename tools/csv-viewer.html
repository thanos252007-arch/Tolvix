How to view a CSV file

  1. Open your CSV file in a text editor or spreadsheet and copy its comma-separated contents.
  2. Paste the contents into the CSV text box. You can also type a small CSV sample directly.
  3. Select Preview CSV to display the parsed rows and columns in a table.
  4. Check the header row and a few values to confirm that commas, quotation marks and line breaks have been interpreted as intended.
  5. Select Clear before previewing another dataset.

Example CSV data

Paste this sample into the viewer to see a header row and three records:

name,city,orders
Asha,"Pune, Maharashtra",12
Ravi,Mumbai,8
Meera,Nashik,15

The comma inside "Pune, Maharashtra" stays within one field because the value is quoted. The first row is displayed as the table header.

How CSV commas and quotation marks work

CSV (comma-separated values) stores records as rows and separates fields with commas. If a field itself contains a comma, a double quote or a line break, it should be enclosed in double quotes. A double quote inside a quoted field is commonly represented by two double quotes. This viewer supports quoted fields and escaped double quotes for this format.

For example, "Pune, Maharashtra" is one field, not two. A value such as "She said ""hello""" contains quotation marks inside the field.

Limitations and privacy

The preview is limited to 5,000 rows and 100 columns for browser stability, and the input is limited to 2 MB. This is a viewer, not a spreadsheet editor: it does not calculate formulas, edit cell formatting, manage multiple sheets or export a modified workbook. It parses comma-separated data; it does not provide a delimiter-selection control.

CSV parsing and table rendering run in your browser. Tolvix does not upload the CSV text to its own processing server for this tool. Frequently asked questions

Why does a comma inside a value create another column?

Fields containing commas need to be enclosed in double quotes in standard CSV data. For example, write "Pune, Maharashtra" as one field.

Does the viewer support quoted fields?

Yes. It supports quoted fields and doubled double quotes inside quoted values. Check that the source CSV follows those conventions if the preview looks misaligned.

Can I edit formulas or spreadsheet formatting here?

No. The viewer displays parsed CSV values as a table. Use a spreadsheet application if you need formulas, formatting, multiple sheets or editing features.

Is my CSV uploaded to Tolvix?

No. This tool parses the text in your browser and does not send the CSV to a Tolvix file-processing server. Normal hosting and analytics requests are covered in the Privacy Policy.
