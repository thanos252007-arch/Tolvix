Understand binary, decimal and hexadecimal

Decimal uses ten digits (0–9), binary uses two (0 and 1), and hexadecimal uses sixteen symbols (0–9 and A–F). The same integer can be written differently in each base. For example, decimal 255 is binary 11111111 and hexadecimal FF. The value is unchanged; only its representation changes.

Common developer uses

  • Binary is used to inspect individual bits and bit masks.
  • Hexadecimal is common for memory addresses, byte values and colour notation.
  • Decimal is the everyday number system used in most user-facing calculations.

Check whether the input is intended to be an integer and whether leading zeros are meaningful in your context. Converting a number does not preserve formatting conventions such as fixed-width fields unless those are handled separately.
