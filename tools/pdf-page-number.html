How to use

Add page numbers to PDF pages. Choose your file or enter the requested content, select options, then run the tool and download the result.

Choose a numbering convention

Page numbering can start at the first page or begin after a cover, title page or contents section. Decide whether the visible number should match the PDF viewer's page position or a printed document convention. If front matter uses Roman numerals or a later section restarts at page 1, check the intended sequence before applying numbers.

Check placement and sequence

  • Preview the first numbered page and the final page.
  • Check that numbers do not overlap existing footers or page content.
  • Inspect pages with different orientations or margins.
  • Keep a copy of the original PDF until the result is approved.

Visible page numbers do not necessarily change the PDF's internal page labels, bookmarks or table of contents. Verify any recipient-specific formatting requirements before submitting the file.

Privacy and limitations

Processing happens locally in your browser. The page loads standard analytics and, for PDF tools, a third-party PDF library. Some advanced document features may not survive conversion. Check outputs before relying on them.

Frequently asked questions

Are my files uploaded?

No. File processing runs in your browser; the selected file is not sent to a Tolvix processing server.

Will all features be preserved?

Not always. Browser-based conversion may not preserve every annotation, form, font or advanced document feature.
