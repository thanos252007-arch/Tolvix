How to use

Crop an image using pixel coordinates. Choose your file or enter the requested content, select options, then run the tool and download the result.

Plan the crop before exporting

Cropping removes pixels outside the selected rectangle. It can improve composition, fit a profile-picture frame or focus attention on a subject, but removed areas may not be recoverable from the cropped output. Keep an untouched original if you might need a different crop later.

Crop accurately

  • Check the image dimensions before entering pixel coordinates.
  • Keep the crop rectangle within the source image boundaries.
  • Use a consistent aspect ratio when preparing a set of thumbnails or profile images.
  • Preview the result to ensure faces, labels and important edges are not cut off.

Cropping changes the visible area; it does not blur or securely redact private information. If you need to hide sensitive details, use a proper redaction method rather than relying on a crop that may leave the original elsewhere.

Privacy and limitations

Processing happens locally in your browser. The page loads standard analytics and, for PDF tools, a third-party PDF library. Some advanced document features may not survive conversion. Check outputs before relying on them.

Frequently asked questions

Are my files uploaded?

No. File processing runs in your browser; the selected file is not sent to a Tolvix processing server.

Will all features be preserved?

Not always. Browser-based conversion may not preserve every annotation, form, font or advanced document feature.
