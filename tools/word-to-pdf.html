How to save text as a PDF

  1. Type or paste your plain text into the Document text box.
  2. Select Print / Save as PDF to open your browser's print dialog.
  3. Choose Save as PDF as the destination or printer.
  4. Review the page preview, paper size, margins and scale, then save the PDF.

Example: Paste meeting notes or a simple text document, open the print dialog and save the preview as a PDF file.

Limitations and privacy

This tool prepares plain text for printing. It does not import DOCX files or preserve Word layouts, images, tables, headers or footers. Choose “Save as PDF” in the print dialog.

The text is prepared for printing in your browser and is not uploaded to a Tolvix processing server. The tool accepts up to 100,000 characters. Browser print settings can change page breaks, margins and fonts, so check the preview before saving. Avoid using sensitive text on shared devices. Frequently asked questions

How do I save my text as a PDF?

Enter or paste your text, choose the available formatting options, then open your browser's print dialog and select Save as PDF.

Will the PDF look exactly the same on every device?

Margins, fonts and page breaks can vary by browser and print settings. Preview the pages and adjust scale or margins before saving.

Can I convert a DOCX file with this tool?

No. This tool accepts typed or pasted plain text. It does not open DOCX files or preserve Word formatting, images, tables, headers or footers. For complex documents, export to PDF from the application that created the document.
