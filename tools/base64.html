What Base64 does and does not do

Base64 represents binary data using a text-safe alphabet. It is commonly used to place small data values in text-based formats, email content and data URLs. Encoding changes the representation, not the secrecy of the information. Anyone who has the encoded value can usually decode it without a password.

Common Base64 troubleshooting

  • Copy the complete encoded string, including any required padding characters.
  • Remove unrelated labels or quotation marks that are not part of the value.
  • Check whether the source is ordinary text or binary data; text decoding may not display arbitrary binary bytes correctly.
  • Do not treat Base64 as encryption, password protection or a secure way to store credentials.

For Unicode text, the same visible characters can be represented by multiple byte encodings. If decoded text looks incorrect, check the character encoding used by the system that produced it.
