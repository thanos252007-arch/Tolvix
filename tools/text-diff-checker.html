How to use

Limitations and privacy

This is a straightforward line-by-line comparison. It does not compute a minimal edit script or character-level changes; moved lines may appear as removals and additions.

Processing runs in your browser except for loading the PDF processing library from jsDelivr on the PDF Page Extractor page. Avoid entering secrets or confidential data into websites unless you have reviewed their privacy practices. Read the Privacy Policy and Terms of Use.

Frequently asked questions

How do I compare two versions of text?

Paste the original text in one box and the revised version in the other, then run the comparison to identify changed lines.

Can this compare source code?

Yes, it can help inspect text-based code changes. It is a simple text comparison, not a Git diff, syntax-aware review or substitute for tests.

Is my text uploaded?

Comparison runs in your browser. Do not use a shared device for sensitive drafts, and see the Privacy Policy for site-wide analytics and third-party requests.
