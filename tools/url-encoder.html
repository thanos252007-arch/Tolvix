Why URL encoding is needed

URLs use a limited set of characters in specific positions. Characters such as spaces, ampersands and non-ASCII text may need percent-encoding when they are included as data in a URL component. A space is commonly represented as %20 in a URL, although form-encoded data may use a plus sign.

Encode the correct part of a URL

A complete URL contains separate parts such as the scheme, host, path, query and fragment. Encoding an entire URL as though it were one value can also encode separators such as slashes, question marks and ampersands. Usually, encode the individual value that will be placed inside a query parameter, not the full address.

Encoding is not encryption. Do not put passwords, private tokens or confidential data in a URL; URLs can be stored in browser history, server logs and referrer information.
