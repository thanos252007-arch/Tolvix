Prepare JSON for a spreadsheet

JSON-to-CSV conversion is most straightforward when the input is an array of objects with a consistent set of properties. Each object becomes a row and its property names become column headings. Nested objects and arrays do not fit naturally into a flat table, so check how complex values are represented in the output.

Review the CSV before importing

  • Check that every record has the expected fields.
  • Look for commas, quotation marks and line breaks inside values.
  • Remember that spreadsheet applications may interpret dates, long numbers and leading zeros automatically.
  • For identifiers such as postal codes, account references or product codes, import the column as text when formatting must be preserved.

CSV is a plain-text table format. It does not retain JSON nesting, data types or application-specific metadata unless you preserve those details separately.
