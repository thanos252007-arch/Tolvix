How to use

Conservatively reduce JavaScript whitespace. Choose your file or enter the requested content, select options, then run the tool and download the result.

Minify only after checking the source

JavaScript minification can shorten identifiers and remove whitespace or other code that the minifier determines is unnecessary. It is a build optimisation, not a security measure: minified code can still be inspected and should never contain secrets such as private API keys. Keep readable source files and use source maps in your development workflow when appropriate.

Test the minified script

  • Run the original code's tests before and after minification.
  • Check browser console errors and important interactions.
  • Verify that any required global names or externally referenced function names are preserved.
  • Review licence notices and third-party attribution before publishing.

Minification can expose issues in code that depends on unusual runtime behavior. Review the output and test it in the environment where it will run.

Privacy and limitations

Processing happens locally in your browser. The page loads standard analytics and, for PDF tools, a third-party PDF library. Some advanced document features may not survive conversion. Check outputs before relying on them.

Frequently asked questions

Are my files uploaded?

No. File processing runs in your browser; the selected file is not sent to a Tolvix processing server.

Will all features be preserved?

Not always. Browser-based conversion may not preserve every annotation, form, font or advanced document feature.
