Create a QR code from a link or text

A QR code is a scannable, square pattern that can open a website or display text on a phone. Use this free QR code generator to create a code for a website, event page, menu, contact instructions or a short message. Enter the content above and select Generate QR code.

How to generate and download a QR code

  1. Enter a complete website address (for example, https://example.com) or the text you want to share.
  2. Click Generate QR code and wait for the preview to appear.
  3. Scan the preview with your phone camera to test that it opens the intended content.
  4. Select Download QR code to save the image as a PNG.
  5. Test the saved image again before printing or sharing it.

Example uses

  • Website: put a QR code on a flyer so visitors can open your website.
  • Restaurant menu: link to a public menu page.
  • Event: share a public registration or information page.
  • Printed material: add a code to a poster or business card and test it at the final printed size.

Important privacy note

To create the image, the text or URL you enter is sent to the third-party QR image service api.qrserver.com. Do not enter passwords, private documents, personal records, payment details or other confidential information. Read our Privacy Policy · Terms before using the site.

Frequently asked questions

Is this QR code generator free?

Yes. The Tolvix interface is free to use and does not require an account. QR image generation depends on the external service being available.

Can I create a QR code for any website?

You can enter a public URL. Check that the address is correct and that the destination is safe before sharing the code.

Can I download the QR code?

Yes. After the preview appears, use the Download QR code button to save a PNG image.

Will a QR code expire?

A QR code generated from plain text or a fixed URL does not have an automatic expiry date. However, a linked website can move, change or stop working.
