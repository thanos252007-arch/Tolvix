Static QR codes: what happens if the link changes?

This generator creates a code from the URL or text you enter. The information is encoded in the QR image; Tolvix does not provide a managed redirect or dynamic QR-code editing service. If you encode a fixed website URL and later move that page, the QR image does not automatically change. You will need to create and distribute a new code, unless the destination URL itself continues to redirect to the new page.

A QR code containing plain text keeps displaying that encoded text. A QR code containing a website URL can still be scanned when offline, but opening the website normally requires an internet connection.

How to make a QR code that scans reliably

  • Use a clear, high-contrast design, usually a dark code on a light background.
  • Keep the blank margin around all four sides; do not crop the QR code tightly.
  • Do not stretch, skew, blur or cover parts of the code.
  • Use a stable destination URL and check that it loads correctly.
  • Print a sample at the final size and scan it from the distance people will use.
  • Test the downloaded PNG on more than one phone when possible.

Do QR codes expire?

A basic QR code containing fixed text or a URL does not have an automatic expiry date. However, the linked website can move, change or stop working. The Tolvix generator does not manage dynamic redirects.

Can I edit a QR code after printing it?

No. The content is encoded in the image. If the URL or text needs to change, generate a new QR code and replace the old printed copies.

Can I use this QR code on a poster, menu or business card?

Is it safe to put private information in a QR code?
