Prepare lines for sorting

Line sorting is useful for alphabetising names, keywords, labels and simple lists. The result depends on how the tool compares characters, letter case, punctuation and numbers. If the list contains identifiers such as item-2 and item-10, ordinary alphabetical order may place them differently from the natural numeric order you expect.

Check the sorted list

  • Remove blank lines if they should not be included.
  • Decide whether duplicate entries should remain.
  • Check names with accents or non-English characters.
  • Keep related multi-line records together; sorting individual lines can separate data that belongs together.

For structured records, sort by a specific column in a spreadsheet or database rather than sorting each line of a text export independently.
