Whitespace can affect copied text

Text copied from PDFs, websites and spreadsheets can contain repeated spaces, tabs or unexpected blank lines. Cleaning whitespace can make a paragraph easier to read or help prepare text for another application. However, whitespace can be meaningful in source code, fixed-width data, tables and preformatted examples.

When to preserve spacing

  • Do not clean code indentation unless you understand the language and formatting rules.
  • Check tab-separated data before replacing tabs with spaces.
  • Keep paragraph breaks when they separate different ideas.
  • Compare the cleaned output with the original before pasting it into a form.

This tool changes whitespace characters; it does not proofread the text or determine which line breaks are semantically important.
