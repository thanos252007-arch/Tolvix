How to use

Edit title, author, subject and other PDF metadata. Choose your file or enter the requested content, select options, then run the tool and download the result.

What PDF metadata can contain

PDF metadata fields can include a document title, author name, subject and keywords. These values help document libraries and search tools describe a file, but they are not the same as the visible text on the PDF pages. Some documents also contain metadata in XMP packets or application-specific fields that a basic editor may not change.

Review metadata before sharing

  • Use a clear title that describes the document.
  • Remove outdated author or subject information when appropriate.
  • Check the saved PDF in another viewer to confirm the fields changed.
  • Remember that metadata editing does not remove personal information from the visible page content.

Changing a few metadata fields is not a complete privacy scrub. If a PDF contains comments, attachments, hidden layers or sensitive text, inspect those separately before publishing it.

Privacy and limitations

Processing happens locally in your browser. The page loads standard analytics and, for PDF tools, a third-party PDF library. Some advanced document features may not survive conversion. Check outputs before relying on them.

Frequently asked questions

Are my files uploaded?

No. File processing runs in your browser; the selected file is not sent to a Tolvix processing server.

Will all features be preserved?

Not always. Browser-based conversion may not preserve every annotation, form, font or advanced document feature.
