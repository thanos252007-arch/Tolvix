Free online JSON formatter and validator

JSON (JavaScript Object Notation) is a text format commonly used to exchange data between websites, applications and APIs. When JSON is compressed onto one line, nested objects can be difficult to inspect. This free JSON formatter makes valid JSON easier to read with indentation, or reduces it to a compact string with minification.

What this tool does

  • Pretty print: adds indentation and line breaks to valid JSON.
  • Minify: removes unnecessary whitespace while keeping the JSON data unchanged.
  • Validate: attempts to parse your input and displays a syntax error if it is not valid JSON.

How to format JSON

  1. Copy your JSON data from a file, API response or code editor.
  2. Paste it into the Your text box.
  3. Choose Pretty print to format it or Minify to compact it.
  4. Click Run tool. If the input is valid, the formatted result appears below.
  5. Use Copy result to copy the output.

Example

Input JSON: {"name":"Asha","city":"Pune","active":true}

Pretty-printed output:

{
  "name": "Asha",
  "city": "Pune",
  "active": true
}

Minified output: {"name":"Asha","city":"Pune","active":true}

Common JSON errors

  • Use double quotes around property names and string values.
  • Remove trailing commas after the final item in an object or array.
  • Match every opening brace { with a closing brace }, and every opening bracket [ with ].
  • Use valid JSON values such as strings, numbers, booleans, arrays, objects or null.

Frequently asked questions

Does formatting change my JSON data?

Pretty printing changes whitespace and indentation, not the represented values. Minifying also removes unnecessary whitespace. Always review important output before using it in production.

Can this tool fix invalid JSON automatically?

No. It reports a parsing error to help you locate a problem, but you must correct the input yourself.

Is my JSON uploaded?

Formatting and parsing happen in your browser. The JSON text is not sent to Tolvix for processing. Avoid pasting secrets into any website and review the Privacy Policy · Terms.

JSON formatting tips for API responses

When inspecting an API response, format the JSON first, then expand nested objects and arrays to locate the field you need. Check whether a value is a string, number, boolean, array, object or null; these types are not interchangeable. If a response contains personal data, remove or mask it before sharing examples or screenshots.

Validate before using the output

A successful parse confirms that the input follows JSON syntax. It does not confirm that the data matches an API schema, contains required fields or is safe to use. Check application-specific requirements separately.
