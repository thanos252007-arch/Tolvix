Use generated passwords safely

A longer password with a varied character set is generally harder to guess than a short, predictable one. Use a different password for every important account and store it in a reputable password manager. Avoid names, birthdays, keyboard patterns and words associated with you.

Important security habits

  • Generate a unique password for each service.
  • Do not reuse a password across email, banking and social accounts.
  • Enable multi-factor authentication wherever it is available.
  • Never paste a generated password into a public issue, shared document or untrusted website.

This tool generates a password in your browser. Your device, browser extensions, clipboard history and the website where you use the password are still part of your security environment. For critical accounts, consider using a trusted password manager with its own secure generator.
